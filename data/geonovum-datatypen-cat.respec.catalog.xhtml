Gegevensdefinitie

datatypen-overig - overzicht

Overzicht van overige door Geonovum gebruikte datatypen.

Opmerking: Deze primitieve datatypen zijn een restgroep omdat ze wel worden gebruikt in een aantal door Geonovum beheerde informatiemodellen maar niet behoren tot de twee andere geïdentificeerde groepen primitieve datatypen ISO 19107 of MIM.

Een aantal komt uit ISO 19103:2024 maar zit niet in de MIM primitieve datatypen. Dit kan mogelijk aangepast worden.

Primitieve datatypen

Primitief datatype Binary

Naam Binary
Begrip http://definities.geostandaarden.nl/geonovum/id/concept/Binary
Herkomst 19103
Definitie

Data type dat een string van bits representeert
Herkomst definitie
Datum opname
Toelichting

Een bit heeft twee symbolen die 0 en 1 representeren als waarde domein.
